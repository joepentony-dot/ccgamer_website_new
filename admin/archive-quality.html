Audit boundaries

The full audit checks required catalogue fields, duplicate identifiers, local thumbnail, audio, optional 3D-box and canonical page files, plus local image file size. External Google Drive, Lemon64 and YouTube availability cannot be proved reliably from a browser without a server-side service, so this report validates their format and supplies direct review links rather than labelling an unreachable third-party request as broken.
