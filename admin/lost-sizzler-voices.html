How Overrides Work

  • Custom first: an enabled recording is used instead of speech synthesis for that cue.
  • Several takes: upload several versions of “Ow!”, “Low health”, etc. and the game varies them automatically.
  • Use Default: disables every custom recording for one cue without deleting the files. The normal British-English browser voice then takes over again.
  • Test: previews an enabled custom clip; if none is enabled, it speaks the built-in fallback line.
  • Safe fallback: a missing or failed recording never stops the game. The spoken fallback remains available.
Recording tip: short, tightly trimmed clips work best. Avoid long silence at the beginning or end.
