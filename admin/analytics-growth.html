Measurement notes

  • Registrations: exact Supabase account figures.
  • Google Analytics: consent-based, so figures represent tracked visitors rather than every visitor. CCG GA4 property 526769734 is configured directly, so Analytics Growth does not require Analytics Admin API property discovery.
  • Search discovery: Search Console uses finalized data and normally trails live traffic by a few days.
  • YouTube attribution: identifiable referrals are shown automatically; UTM-tagged links in video descriptions and pinned comments make attribution stronger.
  • Privacy: Google OAuth tokens stay in browser memory for the current admin session and are not stored in the public repository.
