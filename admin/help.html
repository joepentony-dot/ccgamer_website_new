Admin Help & Instructions

CCG Admin Panel workflow

  1. Start local server: python -m http.server 8000.
  2. Open /admin/dashboard.html and confirm status panel.
  3. Open Games Editor, edit/add drafts, then run Validate Library.
  4. Use Integrated Export Panel: download games.json, SEO stubs, and package if required.
  5. Replace repository files manually (/games/games.json, generated pages/sitemap as needed).
  6. Open /admin/publish.html and complete all 7 publish checklist steps.
  7. Commit, push, and verify production pages.

Safety rules

  • No auto-write to repository files from browser tools.
  • All exports are client-side downloads.
  • Use diff viewer before export for regression safety.
  • Mark publish steps complete to keep workflow traceable.

Legacy pages

Legacy admin pages are still available for reference but are deprecated. Use Dashboard, Editor, Publish, and Help as the primary CMS flow.
