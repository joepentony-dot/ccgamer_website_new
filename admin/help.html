Admin Help & Instructions

What changed

  • Unified Omega navigation is available on all core admin pages.
  • Games Editor now supports Add New Game draft creation and export download flow.
  • Publishing remains static-host safe: no server writes, manual commit required.

How to use

  1. Run python -m http.server 8000.
  2. Open /admin/dashboard.html.
  3. Go to Games Editor, fetch library, edit or add drafts.
  4. Download games.json, replace repository file manually.
  5. Use publish pipeline checklist and run local scripts if needed.
