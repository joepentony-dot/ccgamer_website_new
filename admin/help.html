CCG Admin Guidance

Admin Help & Workflow

The normal publishing route is now the unified CCG Content Publisher. Legacy editors remain available for recovery and specialist maintenance only.

Normal publishing workflow

  1. Open CCG Content Publisher.
  2. Choose Add Game or Add Video / Feature.
  3. Enter the source information once. For videos, paste the YouTube URL; the publisher extracts the video ID automatically.
  4. Review the form validation and publish. The publisher writes only the authoritative source data and any selected game thumbnail.
  5. Existing GitHub workflows then regenerate the canonical pages, verified YouTube metadata, VideoObject/Clip structured data, video library, archives and sitemaps.
  6. Use the Publishing Status tab to follow the automated stages and confirm the final canonical URL is live.
  7. After the content is live, use Announcements if you want to notify opted-in members.

Video publishing

  • The YouTube Data API key stays in GitHub Secrets and is never displayed by the browser admin tool.
  • Verified upload dates, durations, titles and thumbnails are fetched by GitHub Actions after the source entry is published.
  • If YouTube does not return a video, the site withholds unverified VideoObject fields rather than inventing them.
  • YouTube descriptions containing timestamps can feed visible chapters and Google Clip/Key Moments markup during the SEO generation step.

Games

  • The Content Publisher updates the authoritative /games/games.json source and can commit a selected thumbnail atomically.
  • The existing Reliable Games Publishing workflow remains responsible for generated game pages, search/index files, archives and game sitemap output.
  • Do not hand-edit generated game pages or sitemap files when the normal publisher can generate them from source data.

Tools & diagnostics

  • Member Hub Health — diagnose member-area data and service health.
  • Archive Quality — inspect archive/data quality and maintenance issues.
  • Legacy Game Builder — fallback package/export workflow for exceptional recovery or comparison work.
  • The old bulk JSON editor remains available by direct URL only. It is intentionally removed from normal navigation because it is not part of the day-to-day workflow.

Safety rules

  • Never paste the YouTube API key into an admin form, source file, issue or chat. It belongs only in the GitHub secret YOUTUBE_API_KEY.
  • Use the Content Publisher as the source-entry layer; let the existing generators own derived pages and XML files.
  • Keep legacy editors available as fallbacks rather than deleting recovery paths.
  • Use the publishing status and GitHub validation checks before treating a new entry as live.
