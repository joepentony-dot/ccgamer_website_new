CCG Admin Publish Workflow

Publish Pipeline Wizard

Complete steps in order. You can continue if needed, but skipped prerequisites will be flagged.

Step 1 — Download latest exports

From Editor, export the latest games.json and SEO bundles.

Go to Export Panel

Warning: run this before all other steps.

Step 2 — Replace /games/games.json

Copy downloaded file into repository path /games/games.json.

Warning: using stale games.json can publish old content.

Step 3 — Run SEO/Node scripts

Generate slug pages and sitemap assets from your local Node workflow.

node scripts/generate-slug-pages.js
node scripts/generate-sitemaps.js

Warning: skipping scripts can break discoverability and links.

Step 4 — Git status check (manual)

Review working tree and verify intended changes only.

git status

Warning: review changes before commit.

Step 5 — Commit

Create a clear commit message for export + generated files.

git add games/games.json games/* sitemap*.xml
 git commit -m "Update games and generated SEO assets"

Warning: no commit means no deployment change.

Step 6 — Push

Push to your main publish branch.

git push

Warning: not pushed yet, GitHub Pages cannot update.

Step 7 — Verify live

Open live site, validate updated game page and sitemap availability.

Open live site

Warning: always perform post-publish verification.

Step 8 — Trigger new game email (optional)

After publishing a brand-new game, send one notification blast to opted-in members.

Warning: only trigger once per new game publish.
