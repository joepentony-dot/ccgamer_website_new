How the game uses assets

  • GitHub remains the fallback. Removing a custom asset immediately returns that slot to the bundled artwork.
  • Supabase Storage holds live uploads. No GitHub token is exposed in the browser.
  • One active file per slot. Replacing a slot removes the old stored file after the new record is saved.
  • Music loops by level. Game sound effects continue over uploaded music.
Graphics workflow: upload source art here. Detailed raster art should normally stay PNG/WebP. Flat logos/icons can be vectorised to SVG when that improves scaling.
