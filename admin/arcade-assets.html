Recommended visual workflow

  • Main background: one full 1600×900 scene image.
  • Back / Mid / Front layers: transparent PNG/WebP/GIF overlays for depth, lights, signs, desks, snow, CRT animation and foreground scenery.
  • Sprite sheets: keep every animation frame in one transparent image and map frame numbers here.
  • GitHub remains the fallback: deleting or disabling an upload immediately restores the bundled asset.
  • Supabase Storage holds live uploads: no GitHub credentials are exposed to the browser.
Animated images: animated GIF/WebP can be used for scenery and effects. For characters, sprite sheets are preferred because the game controls the exact animation state and timing.
