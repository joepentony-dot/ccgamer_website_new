Background & Audio Workflow

  • Lost Sizzler music: choose a slot under Lost Sizzler Music, then upload an MP3, OGG or WAV. Reload the game and that track replaces the bundled music for that situation or room.
  • Fallbacks stay intact: leave a music slot empty, disabled or delete it and The Lost Sizzler automatically uses its bundled soundtrack instead.
  • Main backgrounds: use one finished 1600×900 scene image for each Arcade Quest game section.
  • Animated scenery: GIF or WebP can be used if you want movement in a background.
  • Gameplay art is protected: production character animation, enemies, bosses, hazards, collectibles and power-ups remain versioned with the games so collision and animation behaviour cannot be broken by an accidental upload.
  • Supabase Storage: keeps live background and audio overrides without exposing GitHub credentials.
Music tip: you do not need to fill every Lost Sizzler slot. Add only the tracks you want to replace; all other rooms and encounters continue using the built-in music.
