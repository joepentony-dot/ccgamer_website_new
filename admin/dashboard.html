Quick Start

  1. Open CCG Content Publisher.
  2. Choose Add Game or Add Video / Feature and complete the source details.
  3. Publish once. The automated repository workflows regenerate the page, video SEO, library and sitemaps.
  4. Use Publishing Status in the Content Publisher to follow the automated stages, then announce the content after it is live.
