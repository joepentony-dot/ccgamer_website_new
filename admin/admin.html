        Publish Pipeline (Phase 1)

        This page updates games/games.json and prepares data, but Node + Git run on your machine. Use the buttons below to copy the exact commands in the correct order.

        1. Export your updated games.json using the existing download button in “Exports & Stubs”.
        2. Generate new slug pages (only creates pages that don’t exist):
        node scripts\generate-slug-pages.js
        1. Update sitemaps:
        node scripts\generate-sitemaps.js
        1. Commit + push:
        git add sitemap*.xml games/games.json
git commit -m "Update games + regenerate slug pages + sitemaps"
git push
        1. Google Search Console: submit the HTTPS sitemap index (avoid the HTTP one if it says “Couldn’t fetch”).
        https://www.cheekycommodoregamer.co.uk/sitemap.xml

        Result: new game → games.json → slug page folder → updated sitemap → Google can discover it.
