Admin Panel

Upload, merge and export games without leaving the site. Everything stays client-side so you can vet the JSON before committing.

Nothing is published automatically. You must download and commit manually.

Quick start workflow

  1. Fetch the live games.json or upload a saved file.
  2. Fill out the game form (required fields are flagged).
  3. Stage multiple games, then download the merged JSON.

Handy tips

  • Game ID: lowercase, underscore format (e.g. last_ninja_2).
  • Lemon links: paste one or more Lemon64/LemonAmiga URLs.
  • Description: 1–2 sentences about the game and release.

Adding a New Game — SEO Checklist

  1. Add the game using this admin page.
  2. Ensure the title, thumbnail, and description are filled in.
  3. The slug is auto-derived from the title.
  4. After saving games.json:
    • Run the local SEO generator script to create /games/<slug>.html.
    • Flat files only — GitHub Pages does not support per-game folders.
  5. Commit and push.

2) Add a new game

Creating a new game

When editing an existing game, the ID is locked to prevent accidental changes.

Basics

Required fields marked with *

Use lowercase letters, numbers, and underscores only. No spaces or hyphens.

This controls the SEO URL: /games/your-slug-here/

Description

0 characters (target 180–350)

Write in a direct, personable tone (not “players”). Do not repeat the year (already stored separately). Describe gameplay, feel, and what makes the game notable.

Media

Paste a full URL, a short URL, or just the video ID. We will store the ID only.

Filename only (.jpg, .png, .webp). The path is added automatically.

Links & downloads

Supports Lemon64 and LemonAmiga URLs. Add multiple links if needed.
