Admin Panel

Upload, merge and export games without leaving the site. Everything stays client-side so you can vet the JSON before committing.

Quick start workflow

  1. Fetch the live games.json or upload a saved file.
  2. Fill out the game form (required fields are flagged).
  3. Stage multiple games, then download the merged JSON.

Handy tips

  • Slug ID: lowercase, hyphenated (e.g. last-ninja-2).
  • Lemon links: paste one or more Lemon64/LemonAmiga URLs.
  • Description: 1–2 sentences about the game and release.
