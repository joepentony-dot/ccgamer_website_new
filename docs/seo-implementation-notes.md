# SEO Improvement Notes (Omega-safe)

## Clear title-generation logic

Game titles generated by automation now follow:

`{Game Title} ({Platform}) – {Content Hooks}`

Where content hooks are derived only from available data:
- `Review` only when `ccg_rating_reason` is present with meaningful length.
- `Manual` only when `pdf` exists.
- `Video` only when `videoId`/`videoid` exists.
- `Game Info` always present as fallback.

This prevents false promises and keeps snippets human-readable.

## Top title improvements made (logic level)

- Replaced brand-led fallback (`{Title} | Cheeky Commodore Gamer`) with subject-first title output.
- Added platform clarity (`Commodore 64` / `Amiga`) directly in the title.
- Added content-hook selection tied to real fields so titles describe visible value.

## Pages flagged for manual editorial review (not auto-rewritten)

Use `docs/seo-audit-report.md` priority table and manually review pages with:
- missing/very short descriptions,
- duplicate titles with ambiguous content,
- pages where canonical path intentionally differs for redirect handling.

No game facts were invented and no mass editorial rewrites were made.
