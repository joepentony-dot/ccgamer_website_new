About this publisher

New Generation Software published distinctive early British 8-bit games and programming software. Its catalogue is strongly associated with Malcolm Evans' early 3D work, while its Commodore 64 releases include Shoot the Rapids and The Complete Machine Code Tutor.

Documented company facts

  • The Centre for Computing History preserves New Generation Software titles including 3D Monster Maze, 3D Tunnel and Escape on Sinclair machines.
  • The museum records two Commodore 64 releases under New Generation Software: Shoot the Rapids and The Complete Machine Code Tutor.
