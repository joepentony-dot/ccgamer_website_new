SYSTEM ROMS // ONE-TIME SETUP

Add the C64 system ROMs

The original Commodore 64 BASIC, KERNAL and CHARGEN are supplied automatically by this website on desktop and mobile. If automatic firmware loading fails, you can recover using your own local ROM files here.

ALREADY WORKING ON YOUR DESKTOP?

On your desktop, save its locally installed C64 ROM set. Transfer that file to your phone, then select it here. CCG never receives your ROMs.

Select KERNAL, BASIC and CHARGEN together. The optional 1541 DOS ROM may be included for cycle-driven drive emulation.
