Play Commodore 64 games online — no emulator download

The CCG C64 Emulator runs in your browser on desktop computers, phones and tablets. Search the built-in Commodore 64 game library, select a title and press LOAD to start playing. There is no separate emulator program to download or install.

You can also load your own compatible C64 files, including PRG, D64, D71, D81, G64, TAP, T64 and CRT formats. Use keyboard or gamepad controls on a computer, or the on-screen joystick, FIRE, JUMP, WARP LOAD and optional screen zoom on mobile.

First-time game loading requires an internet connection. Mobile visitors can also add the emulator to their home screen. Read the C64 emulation guide for more ways to play.

CCG C64 // PLAYER SUPPORT

Help & Troubleshooting

New to the emulator, having trouble with a game, or connecting a controller? Select a question below for help.

10 FAQS
01How do I start playing a Commodore 64 game?

Open the game library, search for a title and select it to load the game. You can also drop a compatible C64 game file onto the emulator screen or use the media-loading controls. Some original games take longer to start than others.

02Can I use a Bluetooth or USB joypad on a PC or Mac?

Yes. Pair the controller in your computer’s Bluetooth settings or connect it by USB, then open a game and press a controller button. Compatible gamepads are detected through the browser. Use the D-pad or left analogue stick to move and the A or B button to fire on standard-mapped controllers. If detection fails, try an up-to-date version of Chrome; compatibility depends on your controller and browser.

03My joystick is connected but nothing happens. What can I do?

Start a game, press a button on the controller and look for the GAMEPAD // PORT indicator. Try SWAP JOYSTICK to switch between Port 2 and Port 1: different C64 games expect different ports. If there’s still no response, reconnect your controller, reload the page and try another supported browser.

04Can I play using just my keyboard?

Yes. Select KEYBOARD JOY so it shows ON. Use the arrow keys or WASD for movement and SPACE or CTRL for fire. Click the C64 screen if the keys aren’t responding. Switch KEYBOARD JOY back off when you need the normal C64 keyboard controls.

05Does the emulator work on iPhone, iPad and Android?

Yes, on supported mobile browsers. The on-screen eight-way D-pad lets you move diagonally, with FIRE and other game controls alongside it. You can add the emulator to your home screen too: use Share → Add to Home Screen in Safari on iPhone or iPad, or Chrome’s Install app / Add to Home screen option on Android.

06Why is my game stuck at READY. or taking ages to load?

If a disk game has finished loading but shows READY., type RUN and press RETURN. Some games use a different startup command. Original tape and disk games can also have several loading stages; use WARP SPEED to accelerate loading when available. WARP mutes the audio while active.

07Why am I being asked for Commodore 64 system ROMs?

The emulator doesn’t supply C64 system ROM images. If requested, open ROM SETTINGS and add compatible KERNAL, BASIC and character ROMs that you are entitled to use. A 1541 drive ROM is optional for additional disk-drive functionality.

08Can I save a game and come back to it later?

Yes. In SAVE / RESUME, choose one of the three save slots and select SAVE GAME. When you return, select the game and slot, then choose RESUME SAVE. Saves stay in the same browser unless you export a backup. Export your saves before clearing browser data or changing devices.

09Can I load my own C64 games and cartridges?

Yes. Supported file types include PRG, D64, D71, D81, G64, TAP, T64 and CRT. Drag a file onto the screen or use the relevant loading control under the emulator’s media settings. Multi-disk titles may need a disk swap during play, and some original releases use their own loading commands.

10Why is there no sound, or why is the game running slowly?

Check that MUTE SOUND isn’t enabled, your browser tab isn’t muted and your device volume is up. WARP intentionally silences audio while accelerating loading. If gameplay is slow, close demanding browser tabs and try a current compatible browser. You can also adjust SCREEN SIZE and CRT EFFECT to suit your device.

STILL HAVING TROUBLE? When asking for help, include the game title, your device and browser, the type of controller (if any), and what happens when you try to play.
