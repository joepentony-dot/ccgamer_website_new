Install Cheeky Commodore Gamer

Add CCG to your phone, tablet or computer. It opens in its own app window and keeps a small public offline fallback available.

Return Home

Checking this browser…

Android — Chrome

  1. Open CCG in Chrome.
  2. Tap the three-dot menu.
  3. Choose Add to Home screen or Install app.
  4. Confirm Install.

Windows — Chrome or Edge

  1. Open this page in Chrome or Edge.
  2. Use the install icon in the address bar, or open the browser menu.
  3. Choose Install Cheeky Commodore Gamer or Install this site as an app.
  4. Pin CCG to Start or the taskbar when offered.

iPhone or iPad — Safari

  1. Open CCG in Safari.
  2. Tap Share.
  3. Choose Add to Home Screen.
  4. Tap Add.

What remains online-only

Member profiles, personal ratings, private libraries, notes, submissions and administrator pages are never placed in the public offline cache.

The exact menu wording varies slightly by browser version.
