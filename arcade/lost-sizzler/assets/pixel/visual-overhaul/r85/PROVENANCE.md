# R85 browser sprite provenance

These transparent pixel-art SVG assets were authored specifically for the C64 Dungeon Carnage browser build in this repository.

They are original project assets and do not copy, embed, trace, hotlink or depend on third-party artwork.

## Environment props

- prop-bookcase.svg

The runtime retains deterministic canvas fallbacks so gameplay remains functional if a sprite fails to decode.
