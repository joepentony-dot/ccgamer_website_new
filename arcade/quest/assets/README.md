# Quest 2.0 asset folders

- `production/` — runtime-ready artwork only.
- `source/` — construction parts and working art used to build final sheets.
- `archive/recovered/` — recovered reference material no longer needed at runtime.
- `archive/superseded/` — duplicate or replaced artwork retained for comparison.

Do not point new runtime code at `archive/`. Source assets may be used only as temporary fallbacks while Quest 2.0 sheets are being replaced.
