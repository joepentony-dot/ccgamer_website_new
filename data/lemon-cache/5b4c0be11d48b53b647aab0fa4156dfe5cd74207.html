Gurt 2008-03-25 (10/10)
Lovely game, very atmospheric, very original. Highly recommended.

The aim of the game is to become a "real person", maximise your "pleasure points" (ooer!) and when this is done, you can gain entry to the Pleasuredome. One part of doing this - probably the main part - is a Whodunnit?. The game isn't a murder mystery game, but there is one in it, and the fact that a game can incorporate that with so many other elements such as that evil one brick Breakout "WAR! " game, the ZZT room puzzle, the blitz over Liverpool, gathering flowers and the "talking heads" game speaks volumes about both the game and Denton Designs. Solving the murder mystery doesn't end the game at all; you might only be 30% done by that point, and that's when you're doing other things on the side!

Some random things you can do for points is putting milk in a cat bowl then dropping a cat near it, putting a tape in a VCR, picking up a flak jacket to use in a minigame later and turning lights on. Mostly very mundane, but that's what the game is about - being average, being "real". The game portrays a boring reality with stark vividness and, surprisingly, fun!
