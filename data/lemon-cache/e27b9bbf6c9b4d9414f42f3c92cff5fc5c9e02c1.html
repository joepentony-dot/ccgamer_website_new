Monk 2011-08-12 (10/10)
This correction comes about 8 years too late, I reckon'. Capfuture: it's not a bug. It says: "Press F3 for two players" - which means, it is NOW in one-player mode, and it will change -into- two-player mode IF you press F3. So it always shows the mode that you can get to (by pressing F3), not the mode you are in. So nothing to fix. Also, there are no separate "emulator versions" of games, like some people seem to think - the same exact versions work on both real C64 and the emulators. An emulator mimics (emulates) the functionality of real hardware, so games written for the hardware will (usually) work in the emulator. The games are still the same.

This is the best C64 version of this game (and for me, the best version of this game) - such atmosphere, great graphics (especially compared to the ugly and squeezed-looking ocean version), wonderful sounds (except a bit annoying walking sound) - the original is usually always the best, and that is the case here too. Ocean really screwed up especially in the sound department - also, the 'feeling' just isn't there in the Ocean version, and it seems too hectic and distorted.
