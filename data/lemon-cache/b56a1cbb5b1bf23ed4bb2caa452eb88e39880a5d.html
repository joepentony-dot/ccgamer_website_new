Deist 2024-11-17 (8/10)
I don't mind the occasional pixel hunt, so that never bothered me...
However, here's a design flaw (2 of them actually!) of this game that any point'n'click should avoid:
- Your character DEMANDS to be next to any object you're trying to interact with! This is obviously to increase realism, with the drawback that manipulation in every scene becomes pretty tedious!
- Your character is actually clickable too ( "The hero" ) which, combined with the previous point and the pixel hunting nature of the game means it is constantly in the way when you're trying to click on something!

Also, of note, the original (french) version was literally rife with spelling errors (and real dumb ones at that)! Apparently these game developers didn't use to read a great many books in their spare time, a pity really.... Video games are not all life's about (and the ability to at the very least handle your native language correctly is a bare minimum if you're using half a brain, right?).

All in all, a great game, great story, sure.
But as good as the Delphine Software guys were (and they certainly were that!), their design was still way way behind the immortal glory that Lucasfilm Games came up with later on.
