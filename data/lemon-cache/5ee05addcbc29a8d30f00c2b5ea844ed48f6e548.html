Gordon Bennett 2006-05-18 (10/10)
Regarding those cheats - I couldn't connect to the page, but I found it on archive. Org. Here it is:

$0a63 - spirit
$0a64 - food
$0a65 - rest
$0a66 - stamina
$0a67 - spirit limit
$23bf - remete OK, ha $82-t írsz

I don't know what the last entry is, but the rest are the addresses where the levels are stored. Use a monitor, like the one included in VICE, to use these cheats.

To view the level, type m followed by the address in the monitor. For example if you type "m 0a67" without quotes, the first digit shown will be your spirit limit.

To change it, you replace the number. Don't forget that it is hex, not decimal. So, to change the spirit level to 15 (0f in hex) type "> 0a67 0f" again without quotes. The > is the command to set the value, 0a66 is the address in this case, and 0f is the value. To set food to 9, type "> 0a64 09" and so on.
