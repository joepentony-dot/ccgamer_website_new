Roscoe Empire 2025-10-01 (8/10)
Chris Butler conversions tended to be single load affairs. If the whole game wouldn't go into one load, levels would get jettisoned. It seemed like an ideological stance to prevent an arcade gaming experience from getting broken up by tape multiloading. Of course, in territories like America where disk drive ownership was very high, it would have been perceived as laziness. It's a great looking game that I always found incredibly tough, so missing levels never really came into it. Platform games never really lend themselves too well to joystick control for my liking.

COMMENT: "Without doubt the game which is most closely associated with me. The highscore tune (1) is a copy from the original arcade machine. However, having listened to the in game tune which was a complicated harpsichord tune using lots of channels, I decided to compose my own ghostly tune. Again the tune is not completely original using elements from several sources including Chopin and other bizarre sources (my mom's old organ vinyl records from the 70's). I'm still mystified about why I went for that strange percussion but it seems to work somehow." (MC)
