Quick Start

Follow these steps and you’ll be loading disk images in minutes.

  1. 1) Download + install

    Grab the latest build from the links above. On macOS, allow the app in Security & Privacy if it was blocked.

  2. 2) Point to ROMs

    VICE ships with what it needs; Amiga emulators require Kickstart ROMs. Place them in a clearly labelled folder and set the path in FS-UAE/WinUAE.

  3. 3) Load a game

    Use .d64, .t64 or .prg for C64. Use .adf or WHDLoad packages for Amiga. Then tap Autostart or Insert Disk.

  4. 4) Tune speed + sound

    Enable Exact Cycle Emulation if games run too fast. Reduce latency or buffer size if audio crackles.

Troubleshooting

Controls not working?

Map your USB controller in the emulator preferences. Some devices present as two pads — bind the one that responds.

CRT look & feel

Toggle the site’s C64/Amiga switch for instant theme changes. Most emulators include scanline and CRT filters too.
