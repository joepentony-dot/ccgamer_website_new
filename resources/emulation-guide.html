Emulation Guide

A quick, practical setup sheet for Commodore 64 and Amiga emulation — emulator picks, short setup steps, controller notes, and the most common fixes.

Fast reminders

  • C64 joystick is usually Port 2.
  • Save a “safe config” per system.
  • Amiga often needs legitimate Kickstarts.
  • Use the right machine model for the era.

🕹️ Commodore 64

Recommended emulator: VICE (accuracy + features). Alternative: CCS64 (lightweight).

VICE Accuracy-first, feature packed CCS64 Lightweight, quick booting
Quick-start (VICE)
  1. Install VICE and launch x64 (or the equivalent on your platform).
  2. Load media via File → Autostart disk/tape image.
  3. Set controls via Settings → Joystick settings.
  4. For display: enable Double Size / Fullscreen, then save settings.
Controllers & key mappings
  • Most games assume Joystick Port 2. If input fails, swap ports.
  • Keep a simple mapping profile per genre (platformer, shooter, adventure).
Common issues (fast fixes)
  • Black screen / hangs: use Autostart rather than manual attach.
  • No sound: check audio output device + emulator audio enabled.
  • Too fast: disable warp/turbo and check refresh timing (PAL/NTSC).

🖥️ Commodore Amiga

Recommended emulators: FS-UAE (friendly) and WinUAE (deep control on Windows). Many setups require legitimate Kickstart ROMs.

FS-UAE Friendly launcher experience WinUAE Deep control on Windows Amiberry ARM + Raspberry Pi favourite vAmiga macOS-focused experience
Quick-start (FS-UAE)
  1. Install FS-UAE and the FS-UAE Launcher.
  2. Add your Kickstart ROMs in the launcher.
  3. Load a game (ADF / WHDLoad depending on your setup).
  4. Pick a sensible base model (A500 for many classics), then assign your controller.
Model guidance
  • A500: most “classic” era titles.
  • A1200: later AGA titles and some WHDLoad setups.
  • Memory: start modest — overpowered configs can cause odd behaviour in older games.
Common issues (fast fixes)
  • Kickstart missing: add the correct ROM for the model selected.
  • Disk swapping: use the emulator’s built-in disk manager and verify drive order.
  • Stutter: keep scaling simple; toggle vsync/fullscreen options.

Sources, legality & sensible notes

Emulators are generally legal — the tricky bit is usually the copyrighted content: game files (ROMs / disk images) and Amiga Kickstart ROMs.

Play smart, stay legal

  • Use your own original media where possible, or legitimately purchased re-releases/collections.
  • For Amiga: obtain Kickstarts through legitimate means (bundled solutions or your own dumps).
  • If you’re unsure about the status of a download, treat it as not OK until you’ve verified it.
